# Documentation Skill

Keep one source of truth for each concept. Use the user guide for commands and
behavior, the advanced guide for internals, `CONTEXT.md` for vocabulary, and
ADRs for durable decisions. Write in clear English, prefer examples over
abstract explanations, and use progressive disclosure for long inventories.

Run `composer markdown-lint` and check every new link before finishing.

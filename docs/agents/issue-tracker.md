# Issue Tracker

Doctrine Doctor uses GitHub Issues in `ahmed-bhs/doctrine-doctor`.

## Working conventions

- Use `gh issue` for issue lookup and creation.
- Use the existing labels: `enhancement`, `bug`, `documentation`,
  `code-quality`, `performance`, `analyzer`, `metadata-based`, `query-based`,
  `integrity`, `security`, and `configuration`.
- Do not invent a label. If no existing label fits, leave labels unchanged and
  mention that in the result.
- A spec skill may draft a complete issue, but publishing it is a separate
  external action and requires an explicit user request.
